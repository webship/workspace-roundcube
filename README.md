# @webship.co/workspace-roundcube

Roundcube, the open-source webmail, for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a
builder that makes a real Roundcube in containers with a mail server of its own, its tool, the default mail accounts,
the Roundcube step pack wired into the workspace's testing setup, and its AI items.

The builder, the tools, the tests and CI come with the first release, `1.0.0`.
